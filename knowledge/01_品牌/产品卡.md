# 产品卡

> 只写能确认的事实。拿不准的卖点留空，等店家补充，不要让模型猜。

## 恩施玉露

- 类型：湖北名优绿茶，蒸青工艺
- 卖点：明前头采、清香鲜爽、礼盒体面
- 适合：送长辈、送客户、旅游返程
- 封面关键词：恩施玉露 / 武汉伴手礼 / 湖北特产

## 利川红

- 类型：湖北红茶，暖胃顺口
- 卖点：红艳明亮、甜香、适合秋冬
- 适合：送长辈、日常自饮、节日礼盒
- 封面关键词：利川红 / 红茶礼盒 / 武汉伴手礼

## 楚汉茶礼

- 类型：双拼/组合茶礼盒
- 卖点：一盒尝两种湖北茶、包装有楚汉文化感
- 适合：商务往来、企业定制、外地朋友
- 封面关键词：楚汉茶礼 / 茶礼定制 / 商务伴手礼

## 来凤藤茶

- 类型：恩施来凤地方特色茶
- 卖点：入口微苦、回甘明显、地方稀缺
- 适合：猎奇尝鲜、送懂茶的朋友
- 封面关键词：来凤藤茶 / 恩施特产 / 湖北茶

## 通用卖点（可复用）

- 正宗湖北茶，产地直发
- 礼盒包装，送人拿得出手
- 轻便好拎，返程不占地
- 门店可试喝，满意再带
