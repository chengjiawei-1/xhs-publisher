# 标题公式

> 标题不超过 20 字，前 10 字尽量带“武汉伴手礼 / 湖北特产 / 恩施玉露 / 利川红”这类核心词。
> 不要标题党，不写“震惊”“必看”。

## 1. 送礼场景（场景 + 结果）

`武汉伴手礼｜恩施玉露茶礼盒，走亲访友送超有面儿`

- 前半：城市 + 品类大词
- 后半：送给谁 + 对方的反应

## 2. 旅游场景（限定 + 行动）

`湖北特产恩施玉露茶礼盒，武汉旅游伴手礼不踩雷`

- 前半：地域 + 产品
- 后半：返程/行李箱/不踩雷，给游客一个立刻行动的理由

## 3. 企业/商务场景（结果 + 体面）

`武汉伴手礼恩施玉露茶礼盒，商务出行拿得出手`

- 突出“体面、不失礼、客户有面子”

## 4. 门店/同城场景（实拍 + 福利）

`武汉伴手礼｜门店实拍恩施玉露茶礼盒，到店可试喝`

- 突出“现货、可试喝、同城配送”

## 自检

- [ ] 20 字以内
- [ ] 前 10 字有核心词
- [ ] 有具体场景，不是空泛形容词
- [ ] 没有极限词、功效词
