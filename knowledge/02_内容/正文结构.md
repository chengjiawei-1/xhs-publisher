# 正文结构

> 120–300 字，口语化，2–4 个短段落。核心词自然出现 3–5 次，不要硬堆。

## 五段式

1. **钩子**：一个具体场景
   - “在武汉待了这么久，武汉伴手礼我挑了很久，最后还是选了它”
2. **理由**：2–3 条真实卖点
   - ① 正宗湖北茶，明前头采
   - ② 包装高级，送人倍有面
   - ③ 轻便好拎，返程不占地
3. **使用场景**：怎么送、怎么摆、谁收到
   - “走亲访友拎一盒，长辈当场拆开就夸”
4. **门店/福利**：地址、试喝、评论区互动
   - “📍江陈记茶业（武汉），门店可试喝 / 评论区扣「1」帮你挑”
5. **标签**：2 核心 + 3 长尾 + 3 场景 + 2 同城

## 语言

- 像本地朋友聊天，不像客服
- 句子长短交错，别太工整
- 不写“作为AI”“以下是”
- 不编造用户没提供的价格、奖项、销量

## 自检

- [ ] 第一句能接住标题
- [ ] 核心词 3–5 次
- [ ] 有具体场景，不是空话
- [ ] 没有功效、极限词、导流词
- [ ] 结尾有门店或互动引导
