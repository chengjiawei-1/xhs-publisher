# 风控边界

> 来源：薯管家 AI 托管治理公告、2026 限流细则、江陈记项目实战。
> 记住一句话：**AI 只负责排版和填表，最后一下“发布”必须是人点的。**

## 平台红线

1. 禁止用技术手段模拟真人、做非真实内容或虚假互动
2. 纯 AI 托管发布、主页全是 AI 代发 → 直接封禁
3. 偶发 AI 辅助 → 警告、限流（梯度处理）

## 我们的安全定位

- 插件做：选图、拼图、写文案、填标题/正文/标签
- 人做：核对内容，亲手点“确认发布”
- 对外只说“AI 辅助排版 + 人工确认”，不说“全自动代发”

## 操作规则

| 规则 | 值 |
|---|---|
| 单账号每天 | ≤ 1 条 |
| 发布窗口 | 19:00–20:00（晚高峰前） |
| 同账号间隔 | ≥ 4 小时 |
| 图片 | 同图不复用，发布前查重 |
| 文案 | 同一天多账号相似度 < 60% |
| 发布后 | 30–120 分钟内不做互动 |

## 熔断

- 出现验证码/滑块 → 停该账号 2–3 小时
- 连续失败 ≥ 20% → 停该账号并告警
- 收到“内容违规” → 立即停，记录内容

## 发布前自检

- [ ] 标题 20 字内，前 10 字有核心词
- [ ] 正文无功效、极限词、导流词
- [ ] 标签 6–8 个，无违禁
- [ ] 图片是同一产品多角度，不重复
- [ ] 账号、门店信息正确
